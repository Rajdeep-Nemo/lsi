# Contributing to lsi

Thanks for your interest in contributing!

## Bugs & Suggestions

Found a bug or have a feature idea? Open an issue on GitHub — all feedback is welcome.

## Contributing Code

Everyone is free to contribute! To do so:

1. Fork the repository
2. Create a new branch for your change
3. Make your changes
4. Submit a pull request with a clear description of what you changed and why

## Guidelines

- Keep code clean and commented
- Follow the existing file structure
- Test your changes before submitting
- One feature or fix per pull request

## Code Style

This project uses `clang-format` for consistent code formatting. Before submitting a pull request, format your code using the included `.clang-format` file:

```bash
make format
```
